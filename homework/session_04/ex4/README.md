# Báo cáo Bài 4: Quản lý tệp tin bỏ qua (.gitignore) và Sửa lịch sử (Amend)

## 1. Các bước thực hiện
- Tạo file credentials.txt để giả lập thông tin nhạy cảm.
- Cấu hình file .gitignore để bỏ qua tệp nhạy cảm.
- Sử dụng lệnh git rm --cached để gỡ bỏ file khỏi sự theo dõi của Git nhưng vẫn giữ nguyên file trên đĩa cứng.
- Sử dụng lệnh git commit --amend để chỉnh sửa thông điệp commit gần nhất
